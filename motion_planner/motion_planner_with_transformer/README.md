# 01 — Transformer на синтетических траекториях

В каждой сцене находится 4 автомобиля. Агент с индексом `0` считается
ego-автомобилем. Модель видит историю всей сцены и желаемый маршрут, но
предсказывает только будущую траекторию ego.

```text
истории всех агентов + route polyline → ego future
```

Датасет поровну содержит четыре типа сцен:

1. движение прямо с постоянной скоростью;
2. ускорение или торможение, которое уже заметно в конце истории;
3. левый или правый поворот, заданный маршрутом;
4. движение за лидером: лидер тормозит, остальные реагируют с задержкой.

`scenario_type` хранит номер режима от 0 до 3. Он нужен для анализа, но не
передаётся модели как готовая подсказка.

Здесь изучаем:

- `nn.Linear` для перевода координат в embeddings;
- positional embeddings;
- temporal `TransformerEncoder` для истории каждого агента;
- multi-head attention между агентами;
- отдельный Transformer encoder для маршрута;
- collision rate, отклонение от маршрута, ускорение и jerk;
- hard scenario mining через `WeightedRandomSampler`;
- сравнение обычного обучения и hard mining;
- train/validation loop;
- MSE loss, ADE и FDE.

Запуск:

```bash
python main.py
```
