# 02 — Diffusion для синтетических траекторий

В каждой сцене находятся 4 автомобиля, но планируется только траектория
ego-автомобиля с индексом `0`. Модель получает историю всех агентов и маршрут
ego, после чего создаёт 6 возможных будущих траекторий.

История каждого агента сначала кодируется temporal Transformer. Затем
multi-head attention обменивается информацией между агентами, и diffusion head
предсказывает шум будущей траектории ego. Маршрут кодируется отдельным
Transformer encoder.

Датасет поровну содержит движение прямо, ускорение или торможение, левый или
правый поворот и следование за тормозящим лидером. Маршрут сообщает направление
поворота, но точная динамика будущего всё равно остаётся неоднозначной. Именно
для такой задачи полезна diffusion-модель.

`scenario_type` хранит номер режима от 0 до 3 и пока используется для анализа
распределения, а не как вход модели.

Сложные сцены чаще попадают в обучение через `WeightedRandomSampler`. После
обучения считаются minADE/minFDE по шести сэмплам, collision rate, отклонение от
маршрута, ускорение, jerk и разброс конечных точек.

Обучение:

1. Берём настоящую будущую траекторию.
2. Выбираем случайный diffusion timestep.
3. Добавляем к траектории соответствующее количество шума.
4. Модель получает шумную траекторию, историю и timestep.
5. Модель учится предсказывать добавленный шум через MSE.

Перед обучением координаты делятся на 10, потому что diffusion-процесс устойчивее
работает с величинами порядка `[-1, 1]`. При вычислении ADE/FDE результат снова
переводится в метры.

Inference начинается со случайного шума. За 30 обратных DDIM-шагов модель
постепенно удаляет шум и получает будущую траекторию. Поэтому повторный запуск
`sample()` может дать другой допустимый вариант будущего.

Запуск:

```bash
python main.py
```
